# Dependencies for the newsletter pipeline.
#
# The pipeline has two interchangeable extraction engines (see
# tools/collectors/extract.py):
#
#   modern (default)  trafilatura + feedparser — one code path for every site,
#                     keeps inline links and headings. Needs this file.
#   legacy            standard library only, no install required. Selected with
#                     --engine legacy, or automatically if these packages are
#                     missing.
#
# Setup (a virtualenv keeps the system Python untouched):
#
#   python3 -m venv .venv
#   ./.venv/bin/pip install -r requirements.txt
#   ./.venv/bin/python tools/collect.py --all
#
# The versions below are the exact closure the project is developed and tested
# against, pinned so a fresh clone reproduces the same output. Regenerate with:
#
#   ./.venv/bin/pip freeze
