Three stages

STAGE 1

Collect & aggregate

tools/collect.py → data/collected/. Ten source adapters, standard library only. Every item gets a timestamp, a date_source marker, and a freshness flag.

automatic
STAGE 2

Optional AI processing

tools/ai_apply.py → data/processed/. The model returns decisions only — drop, merge, rank — which this script validates and applies. Raw data is never touched, so any change is auditable and reversible.

semi-automatic
STAGE 3

Render to one file

tools/render_digest.py → site/digest.html. Deterministic, no network, images inlined as data URIs. Works with or without stage 2.

automatic

Why decisions, not edits

PropertyDecision model
Auditableeach change is one inspectable record
Reversibledelete the decisions file, raw data intact
Idempotentre-applying yields the same result
Safeinvalid ids and empty merges are rejected
Testablethe whole pipeline runs with no model at all

Run it

python tools/ai_apply.py
python tools/render_digest.py --indir data/processed --output site/digest.html

Standard library only. No installs, no search tools, no system changes, no network calls in the render step.
