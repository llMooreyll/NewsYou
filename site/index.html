Capture layers

A · stable

RSS and official APIs

Use Podcast RSS, Podcast Index, Reddit OAuth, and the X API when the source, budget, and permissions fit.

B · practical

Public pages

Extract readable text, metadata, links, captions, and show notes from a user-selected public URL.

C · browser

Helium DevTools

Attach to the existing CDP endpoint, use the already-authorized session, and capture only configured pages.

D · resilient

Manual inbox

When a platform changes or blocks automation, a saved URL, pasted passage, or supplied transcript still works.

Evidence

Immutable raw layer

Keep the original capture, method, timestamp, adapter version, checksum, and retention policy.

Editorial

Traceable output

Every summary points back to a source passage or timestamp. Generated text never replaces the original.

Browser proof

The repository includes a dependency-free CDP probe. It opens a separate tab, extracts bounded rendered text and links, records failures, and closes only the tab it created.

python tools/cdp_capture.py https://docs.x.com/x-api/introduction \\
  --output data/browser-captures/x-api.json

No packages are installed. Existing browser tabs are not closed. Browser captures remain local and can be deleted according to the configured retention policy.
