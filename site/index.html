A local-first newsletter pipeline for technology, film, and society. It collects ten sources with plain HTTP, preserves a timestamp and original link for every item, and renders one reviewable digest.

10 sources stdlib only no search tools 中文 + English evidence first

Run it

Standard library only. No installs, no search tools, no system changes.

Read README.md, collectors, AI review step, and architecture. Every item keeps its original link and timestamp; summaries are excerpts, not generated text.
